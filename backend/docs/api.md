# Backend API

前端联调使用的完整中文 API 合同位于仓库根目录：

- [API接口文档.md](../../API接口文档.md)

该合同是当前学生端场景 1、场景 2 的唯一真源，包含：

- 统一响应封装、JWT 鉴权和错误码；
- 注册、登录、个人资料、密码、注销和 Redis 会话；
- 首账户管理员、运行时配置、用户会话管理和不可变审计导出；
- 作业上传、批改任务轮询、作业详情和题目修正；
- 错题本、掌握度、学习概览和分层练习；
- Agent、受限验算沙箱和低置信度策略；

运行中的 FastAPI 还提供交互式 OpenAPI：`GET /docs`，机器可读规范：`GET /openapi.json`。

如果本文件与根目录合同出现差异，以根目录合同和实际后端路由、schema、serializer 为准；修改 API 时应同步更新根合同及公共接口测试。
